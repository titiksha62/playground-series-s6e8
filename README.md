# Data

The dataset is obtained from the Kaggle Playground Series S6E8 competition.

The raw competition files are intentionally not committed to this repository.
Download them from Kaggle and place them in `data/raw/`.

You can download the data from the following link:
https://www.kaggle.com/competitions/playground-series-s6e8/data
